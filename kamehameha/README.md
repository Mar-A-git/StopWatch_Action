# kamehameha: かめはめ波ファームウェア

M5Stack StopWatch 2台を左右の手のひらに着けて、かめはめ波を撃つ。

## 書き込み

VS Code（PlatformIO）で `kamehameha` フォルダを開く。1台ずつ USB でつないで、次の2つを書き込む。

| | 親機（左手） | 子機（右手） |
|---|---|---|
| 1. プログラム | 環境 **env:oya** で Upload | 環境 **env:ko** で Upload |
| 2. 声のファイル | env:oya で **Upload Filesystem Image** | env:ko で **Upload Filesystem Image** |

- 声のファイル（`data/voice/*.wav`）はプログラムとは別に書き込む。書き込まなくても、声なしで動く
- 書き込みが始まらない時は、電源ボタンを約2秒長押しして緑のLEDが点いたら離してから Upload
- 付属の USB ケーブルは充電専用のことがある。PC にシリアルポートが出てこない時は、まずケーブルを疑う

## 遊び方

| ポーズ | 光 | 声 | 振動 |
|---|---|---|---|
| 手のひらを向かい合わせる | ① 中心がオレンジ | か | トン…トン… |
| そのまま溜める（3秒ずつ自動で進む） | ② オレンジ→黄が広がる | め | 少し速く |
| | ③ 黄→白が画面いっぱいに | は | さらに速く |
| | ④ 白い部分が点滅 | め | 点滅と一緒に |
| 両手を前に突き出す | ⑤ 真っ白 → 青白い炎と全色の点滅 | はっ！ | 強く |

- 途中で手を離すとリセット。④のあと5秒撃たなければリセット
- 待機に戻ったら、一度手を離すまで次は始まらない
- 待機中は、画面の下に電池の残量が出る（緑 > 50% / 黄 ≦ 50% / 赤 ≦ 20%、充電中は稲妻）。①が始まると消える
- 確認用に、親機のボタンAで開始・リセット、ボタンBで④の間に発射もできる
- 画面の上に「1 か」などのフェーズ名が出る（`config.h` の `SHOW_PHASE_LABEL` を false にすると消える）

## しくみ

```
  親機（左手）                       子機（右手）
  ・受信レベルで開始／リセットを判断  ←── 1秒20回 ──→  ・親機のフェーズに合わせて光る・鳴る
  ・2台の突き出しがそろったら発射      ESP-NOW        ・自分の突き出しを親機に知らせる
```

- **開始・リセット**: ESP-NOW の受信レベル（RSSI）を使う。StopWatch 同士は、距離より**向き**で受信レベルが大きく変わる。
  手のひらを向かい合わせると -5〜-10dBm、開くと -20dBm より弱くなる（`../rssi_check` で測った値）
- **発射**: IMU の加速度。2台がほぼ同時（0.4秒以内）に 1.8g 以上で動いたら「はっ！」
- **同期**: 親機は「今のフェーズ」と「そのフェーズが始まってからの時間」を送る。子機は遅れた分だけ声の頭を飛ばして、2台の声をそろえる
- **受信レベルの取り方**: この Arduino（2.0.x）の ESP-NOW 受信コールバックには受信レベルが付いてこないので、
  無線をプロミスキャスモードにして、ESP-NOW の電波（Action フレーム）の受信レベルを横から読んでいる
- **描画**: 中心からの距離の表を作っておき、毎フレーム「距離 → 色」の対応表だけを作って全画面を塗る（約18fps）

## 調整

ほとんどの数字は `src/config.h` にまとまっている。

| 定数 | 意味 | いまの値 |
|---|---|---|
| `RSSI_START` / `RSSI_APART` | 開始・離れた判定の受信レベル | -12 / -18 dBm |
| `THRUST_ACCEL_G` | 突き出しの加速度 | 1.8 g |
| `THRUST_PAIR_MS` | 2台の突き出しを「同時」とみなす時間 | 400 ms |
| `PHASE_MS` / `ME2_WAIT_MS` | ①〜④の長さ / ④のあと撃つのを待つ時間 | 3000 / 5000 ms |
| `SPEAKER_VOLUME` | 本体の音量（0〜255） | 240 |
| `VOICE_ON_CHILD` | 子機からも声を出すか | true |
| `FIRE_ON_APART` | 突き出しなしで、手が離れただけで撃つか | false |

シリアル（115200bps）に `[PHASE]`・`[IMU] peak`・`[STAT]` などが出るので、しきい値を決める時の参考になる。

## ファイル

| ファイル | 内容 |
|---|---|
| `src/config.h` | 定数 |
| `src/main.cpp` | フェーズの進め方（親機）・親機に合わせる（子機）・振動・画面の明るさ |
| `src/radio.h` / `radio.cpp` | ESP-NOW。送信は画面とは別のタスク。受信レベルの平均・相手の突き出し・親機のフェーズ |
| `src/effect.h` / `effect.cpp` | 画面の光（同心円のグラデーション・点滅・光の粒・青白い炎） |
| `src/motion.h` / `motion.cpp` | 突き出しの検出（描画の途中でも加速度を読んで、一瞬の動きを見逃さない） |
| `src/voice.h` / `voice.cpp` | 声。起動時に PSRAM へ読み込み、フェーズが変わった瞬間に再生（16kHz・24kHz どちらも可） |
| `data/voice/*.wav` | 声（VOICEVOX:ずんだもん。下の注意を参照） |

## 声のファイルについて

`data/voice/` の WAV は **VOICEVOX:ずんだもん** で作ったもの。この WAV にはリポジトリの MIT ライセンスは適用されない。
使う・改造して配る時は、クレジット「VOICEVOX:ずんだもん」を付け、
[VOICEVOX の利用規約](https://voicevox.hiroshiba.jp/term/) と
[ずんだもんの音源利用規約](https://zunko.jp/con_ongen_kiyaku.html)（禁止事項を含む）に従うこと。

自分で作り直す時の注意: VOICEVOX で母音を長く（1秒以上）伸ばすと、声が崩れて「ジジジ」とノイズが混じる。
伸ばしすぎずに作るのがおすすめ（この WAV は 0.7〜1.2 秒）。
