# stackchan_watch: スタックチャン時計＋かめはめ波

M5Stack StopWatch を腕時計にして、起動メニューでモードを切り替えて使う。

| モード | 内容 |
|---|---|
| スタックチャン時計 | スタックチャンの顔が、時計の**短針と同じように回る**（12時でまっすぐ、1分で0.5度）。数字の時刻は出さない、ちょっと見づらい時計。忙しいエンジニアに「時間を気にするな」と言いたい時計 |
| かめはめ波・左 / 右 | [kamehameha](../kamehameha/) と同じかめはめ波。親機（左手）か子機（右手）かを**メニューで選べる** |
| 空き | **自分のモードを追加できる場所**（`src/custom`） |

> ⚠ かめはめ波は、ドラゴンボールの「かめはめ波」をイメージした非公式のファンメイドです。
> スタックチャン時計も、スタックチャンの非公式のファンメイドです。

解説記事（note）: [スタックチャン時計を追加してみた](https://note.com/mar_69/n/nab9e43a1143e)

## 書き込み

VS Code（PlatformIO）で `stackchan_watch` フォルダを開いて、次の2つを書き込む。かめはめ波で遊ぶ時は、2台とも同じものを書き込む。

1. **Upload**（プログラム）
2. **Upload Filesystem Image**（声）

- [kamehameha](../kamehameha/) から乗り換える時も、**2つとも書き込み直す**（声のファイルの置き場所を広げたので、前の声は読めなくなる）
- 書き込みが始まらない時は、電源ボタンを約2秒長押しして緑のLEDが点いたら離してから Upload
- 付属の USB ケーブルは充電専用のことがある。PC にシリアルポートが出てこない時は、まずケーブルを疑う

### ⚠ フォルダの場所に日本語があると、ビルドに失敗することがある

プログラムが大きいので、フォルダの場所（パス）に日本語などが入っていると、最後のリンクで
`cannot open map file` と出て失敗することがあります。その時は `platformio.ini` の上の方にある

```ini
; [platformio]
; build_dir = C:/pio_build/stackchan_watch
```

の `;` を外して、英字だけの場所を指定してください（ビルドの途中ファイルの置き場所が変わるだけです）。

### Wi-Fi の設定（時刻合わせ）

スタックチャン時計は、Wi-Fi があれば時刻を自動で合わせます。

1. `include/secrets.h.example` をコピーして、同じ場所に `include/secrets.h` という名前で置く
2. `WIFI_SSID` と `WIFI_PASSWORD` を、家の Wi-Fi（2.4GHz）に書き換える
3. 書き込む

`secrets.h` がなくても動きますが、時刻合わせをしないので、**一度も時刻を合わせていない StopWatch では、スタックチャンがまっすぐ（12時）のまま**になります。
`secrets.h` は `.gitignore` に入れてあるので、GitHub には上がりません。

## モードの切り替え

| やり方 | 時計の時刻 |
|---|---|
| **A と B を同時に 1.5秒押す** →「MENU」→ 再起動してメニュー | 消えない（おすすめ） |
| A か B を押しながら電源を入れる → メニュー | 電源ボタンで本当に電源を切ると、時刻は消える（Wi-Fi で合わせるまで表示できない） |

- メニューはタッチで選ぶ（ボタンなら A: 次へ / B: 決定）
- 選んだモードは覚えていて、次からはそのまま起動する
- StopWatch は、電源ボタンで電源を切ると時計（RTC）の時刻が消えます。モードを切り替える時は、電源を切らずに A＋B を使ってください

## スタックチャン時計

| 操作 | 動き |
|---|---|
| 何もしない | 顔が短針と同じに回る。画面の下に電池の残量 |
| A短押し | 表情：ふつう → 笑顔（ピンクのハート）→ 怒り（赤い怒りマーク）→ 悲しい（水色の涙） |
| A長押し（2秒） | 寝る（ミュート）。目を閉じて Zzz。もう一度で起きる |
| B | ずんだもんの声で時刻を喋る（口パク） |
| B長押し（1秒） | 確認用の早送り（12時間を1分で回す）。もう一度で戻る |
| 5分さわらない | 消灯（電池の時はライトスリープ）。ボタンかタッチで点く |

調整は `src/stackchan/config.h`（顔の座標の1 ≒ 0.19mm、画面は約10.5ドットで1mm）。

| 定数 | 意味 |
|---|---|
| `PART_SCALE` / `EYE_SPACING` / `EYE_DOWN` | 目と口の大きさ / 目の間隔 / 目の高さ |
| `FACE_OFFSET_Y` | 顔全体の上下の位置（下に電池があるので少し上げている） |
| `MOUTH_MAX_H` | 口パクで一番開いた時の高さ |
| `SCREEN_OFF_ENABLED` / `SCREEN_OFF_MS` | 消灯するか / 消灯までの時間。有機ELは同じ絵を出し続けると焼き付くことがあるので注意 |
| `SPEAKER_VOLUME` | 声の大きさ |

声は `tools/voice/make_stackchan_voice.py` で作り直せます（VOICEVOX を起動しておく。`--style` で声の種類を変えられる）。

## かめはめ波

遊び方・しくみは [kamehameha](../kamehameha/) と同じです。違いは、親機・子機を**メニューの「左」「右」で選ぶ**ことだけです。

## 自分のモードを追加する（空き）

メニューの右上の「空き」は、`src/custom/custom.cpp` を書き換えると、自分のモードになります。

| 関数 | 役目 |
|---|---|
| `label()` | メニューに出す名前 |
| `drawIcon(g, x, y, r)` | メニューに出すアイコン（(x, y) が中心、r が半径） |
| `begin()` | 選んで起動した時に1回だけ呼ばれる |
| `loop()` | そのあと、ずっとくり返し呼ばれる。中で `M5.update()` を呼ぶ |

- `M5.begin()` と画面の初期化は `main.cpp` で済んでいます
- **A と B の同時押し（1.5秒）は、メニューに戻る操作**です。自分のモードの操作には使わないでください
- 声や画像を使う時は `data/custom/` に置いて、`LittleFS.begin()` してから `/custom/...` で読みます

`custom.cpp` の最初に、簡単な例（A を押すたびに画面の色が変わる）を書いてあります。

## ファイル

| 場所 | 内容 |
|---|---|
| `src/main.cpp` | モードの呼び分け、A＋B でメニューへ |
| `src/menu.*` | 起動メニュー |
| `src/stackchan/` | スタックチャン時計（顔の描画・声・設定） |
| `src/kame/` | かめはめ波 |
| `src/custom/` | 自分のモード（空き） |
| `src/common/` | Wi-Fi / NTP の時刻合わせ |
| `data/stackchan/voice/` | 時刻の読み上げの声（76個） |
| `data/kame/voice/` | かめはめ波の声（5個） |
| `partitions.csv` | 区画。声のファイル用を約10.9MB に広げている |
